Cài đặt phòng họp

1. API key

Key chỉ lưu trên thiết bị của bạn.

2. Cách thảo luận

Đồng thuận: mỗi AI bỏ phiếu + nêu lý do; phòng tự dừng khi tất cả cùng ủng hộ một phương án.

3. Thành viên

Claude (gói Pro): model sonnet (tiết kiệm quota), opus hoặc haiku. Gemini: gemini-flash-latest, gemini-3.1-flash-lite. OpenRouter: model đuôi :free là miễn phí (~50 lượt/ngày nếu chưa nạp tiền); openrouter/free để OpenRouter tự chọn. Bấm vào ô Model để xem gợi ý.
